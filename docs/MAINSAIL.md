# Кнопка синхронизации в Mainsail

На каждом хосте **достаточно одной кнопки** — папка `gcodes` общая для двух принтеров.

## 1. Макрос

После `[include sync-caps.cfg]` в конфиге Klipper доступны макросы:

- `SYNC_CAPS` — основной
- `SYNC_GCODE` — алиас

## 2. Пользовательская кнопка

**Настройки (шестерёнка) → Пользовательский интерфейс → Пользовательские кнопки → Добавить**

| Поле | Значение |
|------|----------|
| Название | Синхронизация CAPS |
| Цвет | по желанию |
| Макрос | `SYNC_CAPS` |
| Подтверждение | рекомендуется: «Загрузить gcode из caps с головного хоста?» |
| Видимость | Desktop + Mobile |

Повторите для **второго принтера** на том же хосте (тот же макрос), если пользуетесь двумя вкладками Mainsail.

## 3. Поведение на мастере

На головном хосте кнопка **не качает файлы по сети** (они уже локально), а только запускает **metascan** для Moonraker на портах `7125` и `7126` — чтобы обновить превью и exclude objects.

## 4. Сообщения

- Успех: `M118` в консоли + запись в `~/printer_data/logs/sync-caps.log`
- Печать идёт: скрипт завершится с ошибкой, в логе будет «Печать активна»
